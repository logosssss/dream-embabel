# v0.1 事实核实

核实日期 2026-10-22。版本以当时 Maven Central 与依赖 pom 为准。

| 项 | 指令写法 | 实际 |
|---|---|---|
| Embabel | 1.5.3，若有更新用最新稳定版 | 使用 1.5.3。官方 java-agent-template 的 parent 也是这个版本 |
| Spring Boot | 4.1.1 | `spring-boot-starter-parent` 4.1.1 |
| Spring AI | 不要手写版本 | `embabel-agent-api` 1.5.3 的 pom 传递 `org.springframework.ai` 2.0.1。本仓库没有 Spring AI 版本号 |
| JDK | 21 | 21 |
| OpenAI 属性 | 先查元数据，不要照抄 Bedrock | `embabel.agent.platform.models.openai.base-url`、`embabel.agent.platform.models.openai.api-key`。key 也可只放环境变量 `OPENAI_API_KEY`。默认模型 `embabel.models.default-llm`。排序模型 `embabel.agent.platform.ranking.llm`。模板注释里的 `embabel.agent-platform.ranking.llm` 与元数据不符，本仓库用元数据那条 |
| OpenAI 模型 id | 以目录为准 | `classpath:models/openai-models.yml` 中的 `gpt-4.1-mini` |
| DeepSeek | 动手时核对官方文档 | 2026-10-22，https://api-docs.deepseek.com/ 。base `https://api.deepseek.com`，对话模型 `deepseek-flash`。旧名 `deepseek-v4-flash` 仍被接受。Embabel 常量 `DEEPSEEK_V4_FLASH` 仍是旧名，配置用 `deepseek-flash` |
| 计划监听 | 用公开 listener，不要反射 | `com.embabel.agent.api.event.AgenticEventListener`。计划事件 `AgentProcessPlanFormulatedEvent`，执行事件 `ActionExecutionStartEvent`。Spring 把全部 `AgenticEventListener` bean 收进 `AgentPlatformConfiguration.eventListener` |
| 测试 API | FakeOperationContext、EmbabelMockitoIntegrationTest | 均在 1.5.3。单测用 `FakeOperationContext.create()`、`expectResponse`、`getLlmInvocations()`。集成测试基类是 `EmbabelMockitoIntegrationTest`，方法有 `whenCreateObject`、`verifyCreateObjectMatching`、`whenGenerateText`、`verifyGenerateTextMatching` |
| 零模型 | 无 key 时跳过真实调用 | `ConfigurableModelProvider` 在模型列表为空时抛出 `No models detected`。`embabel.agent.platform.test.mock-mode` 在 1.5.3 的 jar 里没有调用方。集成测试因此注册一个名为 `test-model` 的 `LlmService`，与基类的 `embabel.models.default-llm=test-model` 对齐 |
| 包名 | 指令原稿写 `com.logosssss.dreamembabel` | 现为 `com.zhu.embabel`，`groupId` 为 `com.zhu` |

三个审校动作都调用 `creating()`，对应测试里的 `createObject`。`whenGenerateText` 在 1.5.3 中存在，本链路没有使用。

## 发布准备

不在这里打 tag，也不 push。本地确认后再执行：

1. 不设置 `OPENAI_API_KEY` 和 `DEEPSEEK_API_KEY`，运行 `mvnw -B clean verify`，结果为成功。
2. 确认没有提交密钥、`application-local.yml`、`.env`。
3. `git tag -a v0.1.0 -m "v0.1.0"`。
4. 等人工决定后再 `git push` 和 `git push origin v0.1.0`。
